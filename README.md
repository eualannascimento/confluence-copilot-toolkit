# confluence-copilot-toolkit

Toolkit mínimo para consultas assistidas em Confluence.

## Configuração

Use CONFLUENCE_BASE_URL, CONFLUENCE_SPACE_KEY e CONFLUENCE_TOKEN somente como
variáveis de ambiente. Nunca registre tokens ou conteúdo confidencial.

## Permissões

Comece com leitura no menor conjunto de espaços. Escrita, exclusão,
administração e alteração de permissões exigem confirmação explícita.

## Testes

Use fixtures locais e execute: python -m pytest
